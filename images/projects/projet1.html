Plateforme Capture The Flag

Développement d'une plateforme interactive de cybersécurité pour l'association Yggame

Docker CTFd Python Cybersécurité Scrum

Présentation du projet

L'association Yggame a pour objectif de promouvoir l'esprit de communauté et d'échange culturel dans le domaine des jeux vidéo. Elle nous a demandé d'intégrer une plateforme axée sur la cybersécurité, intégrant des défis sur plusieurs thèmes, des tutoriels, pour sensibiliser à cette discipline de manière interactive : un "Capture The Flag".

Informations sur la réalisation

Contexte

Projet réalisé dans le cadre de la SAE du 3ᵉ semestre du BUT informatique, en collaboration avec l'association Yggame, en équipe de 5 personnes.

Durée

Un semestre, de septembre 2024 à janvier 2025, divisé en plusieurs sprints selon la méthodologie agile.

Méthode

Méthodologie Scrum avec des sprints de deux semaines. Utilisation de Git (GitLab) pour le versionnement et Docker pour l'hébergement de CTFd.

Contraintes techniques

  • Utilisation du langage C comme catégorie principale de défis
  • Interface conçue pour minimiser la charge cognitive
  • Infrastructure hébergée par l'association
  • Utilisation de CTFd, solution open source
  • Cohérence visuelle et traduction de la plateforme

Résultats obtenus

  • Plateforme intuitive et traduite avec plusieurs catégories : web, C, stéganographie...
  • 3 tutoriels interactifs écrits + 1 vidéo sur la cryptographie
  • 18 défis cryptographie (César, Vigenère, RSA, El Gamal, hachage) avec corrections Python
  • 17 défis OSINT sur la plateforme GallopGram
  • Plateforme GallopGram avec fonctionnalités interactives
