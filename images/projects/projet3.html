Jeu de cartes Trains

Modélisation d'un jeu de cartes inspiré du jeu Trains avec interface graphique JavaFX

Java JavaFX Graphes GitLab Scene Builder

Présentation du projet

L'objectif était de modéliser un jeu de cartes inspiré du jeu Trains, tout en respectant des règles préétablies. Le projet combinait programmation orientée objet, algorithmes de graphes et développement d'interface graphique interactive.

Fonctionnalités

  • Modélisation des règles de jeu
  • Système de graphes pour les trajets
  • Interface graphique interactive
  • Tests unitaires complets

Ma contribution

  • Implémentation des cartes en Java
  • Algorithmes de graphes
  • Interfaces avec JavaFX
  • Tests et validation

Informations sur la réalisation

Contexte

Projet académique réalisé en binôme dans le cadre de la 1ère année de BUT Informatique (semestre 2).

Durée

12 semaines, du 25 mars au 20 juin 2024.

Méthode

  • Environnement IntelliJ IDEA
  • Principes DRY et clean code
  • Git pour la collaboration

Contraintes techniques

  • Langage Java avec programmation orientée objet
  • Algorithmes de graphes pour les réseaux ferroviaires
  • Interface graphique JavaFX avec Scene Builder
  • Structures de données avancées (List, HashMap, Queue)

Résultats obtenus

  • Jeu fonctionnel avec interface graphique interactive et intuitive
  • Gestion complète des règles de jeu modélisées en Java
  • Système de graphes optimisé pour les dynamiques de jeu
  • Consolidation des compétences en Java, JavaFX et algorithmes de graphes
